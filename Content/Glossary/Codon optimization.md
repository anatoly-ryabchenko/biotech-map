The genetic code is _redundant_: a protein is a chain of amino acids, and although there are only twenty amino acids, there are sixty-one three-letter code words (codons) that specify them — so most amino acids can be spelled by several different codons. This means the very same protein can be encoded by an enormous number of different gene sequences. _Codon optimization_ is choosing, among all those equivalent spellings, the one that makes the cell produce the protein best.

It matters because not all synonymous codons are read equally well. A cell stocks different amounts of the small adaptor molecules (transfer RNAs) that deliver each amino acid during protein-building, so a codon matched to an abundant adaptor is translated quickly and smoothly, while a stretch of rare codons makes the protein-building machinery stall. Rewriting a gene to favour the codons a given cell reads fastest can raise protein output substantially. Optimization tunes other features at the same time — avoiding accidental folds in the messenger RNA that would slow reading, and removing signals that could destabilize it.

Codon optimization is used wherever a gene's sequence is written for a cell to read: designing an mRNA drug's coding region, writing the gene a gene-therapy vector will carry, and engineering cells to make a protein. It does not change the protein produced — only how efficiently it is made. The catch is that "optimal" is not fully predictable: pushing codons for maximum speed can occasionally cause the protein to fold wrongly, because the natural rhythm of translation sometimes helps folding — so optimized sequences are tested, not simply trusted.
